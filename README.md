# Street Fighter II playtest

Work in progress. ROM fidelity repairs are underway; this is not a completed arcade-accuracy claim.

[Play the preview](https://mysticalg.github.io/sf2-web-playtest/). Choose WORLD WARRIOR, CHAMPION EDITION or AI EDITION in the main title VERSION row. All modes share the recovered engine and native menus. Keyboard, standard gamepads and touch controls are supported. Enter or punch starts; Esc backs through screens; M toggles sound. AI keeps the original twelve portraits and offers regular Ryu / Evil Ryu Prototype at Ryu, and Ken / Evil Ken at Ken. Other unfinished additions are excluded. At Ryu or Ken, punch selects the original fighter and kick selects the Evil variant (keyboard A/Z; standard gamepad X/A). Touch players tap the labelled choice. Graphics defaults to Original pixels; the selector also offers MMPX Smooth 2x and Smooth 4x (slower), with G to cycle. The explicit [Evil Ryu development matchup](https://mysticalg.github.io/sf2-web-playtest/?edition=ai&prototype=evil-ryu) uses original Ryu graphics and prototype rules. AI online play is disabled.

This repository contains the browser preview only. Every push to main automatically redeploys GitHub Pages.
