# Street Fighter II playtest

Work in progress. ROM fidelity repairs are underway; this is not a completed arcade-accuracy claim.

[Play the preview](https://mysticalg.github.io/sf2-web-playtest/). Choose WORLD WARRIOR, CHAMPION EDITION or AI EDITION in the main title VERSION row. All modes share the recovered engine and native menus. Keyboard, standard gamepads and touch controls are supported. Enter or punch starts; Esc backs through screens; M toggles sound. AI currently has the original twelve in normal selection; unfinished new packs are excluded. The explicit [Evil Ryu development matchup](https://mysticalg.github.io/sf2-web-playtest/?edition=ai&prototype=evil-ryu) uses original Ryu graphics and prototype rules. AI online play is disabled.

This repository contains the browser preview only. Every push to main automatically redeploys GitHub Pages.
